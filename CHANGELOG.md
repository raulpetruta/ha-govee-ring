# Changelog

## 0.2.0

First public release.

- Ring light per device, streamed over the Govee LAN API (DreamView frames, 25 s keepalive). The centre panel stays dark.
- Optional Main light that mirrors your existing Govee light entity and restores white after a ring session.
- `govee_ring.set_segments` action for individual ring zones and gradients.
- Reconfigure to change the IP address, Options to change or remove the Main light.
- Diagnostics with the IP address redacted.
- Brand icon shipped with the integration.
